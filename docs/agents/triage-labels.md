# Triage Labels

| Canonical role | GitHub label | 用途 |
| --- | --- | --- |
| needs-triage | needs-triage | 维护者评估与分诊 |
| needs-info | needs-info | 收集进一步信息 |
| ready-for-agent | ready-for-agent | 规格清楚，可进入实施 |
| ready-for-human | ready-for-human | 由用户或人工实施 |
| wontfix | wontfix | 归档当前实施提议 |

技能提到分诊角色时使用右侧的标签名称。
