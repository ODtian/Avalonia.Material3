## Limits / release handoff

No known missing functional path within the declared bounded **in-window** scope. Existing #13 policies remain the sole modal/focus/back/result owner. Motion, natural sizing, min/max conflict handling and explicit delta arbitration are documented Avalonia projections, not undocumented equivalence claims. The new deterministic partial path is supported; deprecated legacy short-content auto-exclusion is deliberately not a second API.

Not run/claimed: human NVDA/Narrator announcement/reading order; physical touch, multiple-contact hardware, stylus/inertia; Android OS back/IME/software-keyboard/inset integration; macOS/Linux; Native AOT/trimming; release/API compatibility; Android/Compose pixel/shadow/frame/predictive-back conformance. Native Latin/preedit commit does not establish Chinese candidate-session correctness on every IME. Host fonts/localization/back adapters/insets/business values remain host responsibilities.
