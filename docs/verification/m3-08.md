## Acceptance map and explicit boundaries

| Criterion | Delivered evidence / boundary |
| --- | --- |
| Search forms and all Chip variants | Actual bar, docked/full-screen view, both autocomplete fields/dropdowns; assist/filter/input/suggestion, flat/elevated/selected/disabled/avatar/drag feedback; pinned token references in contract |
| Complete edit/choose/add/select/remove/explicit submit | Native editor, public state/methods, pointer/keys, immutable intent including all tokens/remaining text/reason; actual compiled gallery and Windows smoke |
| Public candidates/selection/error | Host IEnumerable/IList/TwoWay selection, setters/attached/native validation and correction; no data service/history/policy hidden in the library |
| Long mixed labels, keyboard, accessibility | 320/200% and wide hosts, wrapped/full accessible labels, genuine scrolling, keyboard/focus/provider/native UIA; human reader and physical touch are **not verified** |
| Gallery/consumer contract/scenarios | Standalone page, runnable SearchHost, per-component contract and explicit source/package scenario links; #20 owns aggregate wiring/release |

Material styling is an Avalonia projection of the locked AndroidX token/component basis, **not formal upstream pixel/animation or complete platform conformance certification**. Autocomplete dropdowns are inline/anchored, and full-screen view placement is host-owned; neither secretly substitutes a platform popup/modal navigation service. Font fallback/licensing, native shadow pixels and touch hardware remain host/platform responsibilities. Native AOT/trimming, Android/other desktop platforms, final API/version release and App upgrade remain #20/platform work.
