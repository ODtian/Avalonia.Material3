## Source / package behavior covered

- Standard/vibrant/segmented recipes plus explicitly separate LegacyDropdown; independent selected color literals in light and dark, live semantic resources, five typography metrics and live uniform/mixed shape roles.
- Check/radio selection is distinct from keyboard highlight; TwoWay binding preserved; disabled/separator skipping; Home/End; horizontal logical navigation; submenu RTL/deepest Escape/result/focus return.
- Actual context request/local point and Menu-key input; hidden/command-disabled anchor convergence; collection removal/all-disabled/empty menu; sibling submenu convergence.
- Native Button input retained in replacement item templates; content, supporting/trailing/icon slots and host command parameter/result behavior.
- Plain tooltip role/name/HelpText, manual1499→1500ms expiry, manual operation with triggers disabled; hover delay/persistence, keyboard-focus lifetime, preserving explicit host descriptions on disposal.
- Rich actual keyboard Tab→Enter action, host result and conditional focus return; pinned baseline28/24; long mixed content and action reachability at320×300 DIP /200%, with no title/body overlap.
- Framed headless touch release/cancel and controlled holding; no ordinary anchor click after accepted long press; multi-contact cancellation. These are not physical-touch evidence.
- Snackbar no focus stealing, correct inverse colors, action/dismiss path, disabled/CanExecute semantics, Closing veto, command-fault noncommit, no hidden undo.
- Covered timeout/cancellation stays actually open until top ownership; stale callbacks cannot close a new generation or run an old action; precanceled Show creates no visual; cancellation-before-UI-dispatch blocks action; root teardown/reopen; forced detach inside an approved command never becomes confirmation.
- Long translated text at320-wide and resized1000-wide hosts, RTL, light/dark and200% fonts, scrolling to reachable actions rather than truncating content.
- Real Gallery interaction changes only named host result and published state; source and isolated package use the same scenarios.
