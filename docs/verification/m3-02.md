## Green suite and package path

Commands:

```powershell
dotnet test tests/Avalonia.Material3.Tests -c Release
pwsh -NoProfile -File scripts/verify-theme.ps1
pwsh -NoProfile -File scripts/verify.ps1
```

`verify-theme.ps1` first runs the source scenarios, then packs `Avalonia.Material3.0.1.0-preview.1.nupkg` into a **new temporary feed**; copies only samples, consumption tests and fixtures (no `src` library); restores a unique empty NuGet cache; compiles both Gallery and StandaloneHost against PackageReference; runs the same theme, reference, gallery and preserved #2 scenarios plus existing package smoke tests. The normal verification script's explicit copy list now includes these new scenarios/fixtures, so it does not silently omit them. Results are `artifacts/TestResults/theme/theme-source.trx` and `theme-package.trx` (normal script uses its original result paths).

A first package-run attempt exceeded a 240-second tool timeout after a slow fresh restore; it is **not counted as a passed package run**. The subsequent invocation with a 600-second allowance completed successfully. Its stale temporary directory was removed without terminating unrelated agents' processes.

Final results are also recorded in the orchestration handoff after merging the latest local integration branch. No package version was bumped and no tracker operation was performed.

## What was and was not verified

Verified: reference values at the public API; default color and token coverage; immediate input changes on existing controls/resources; rendered hover/disabled differences; real headless pointer operations on the actual gallery page; Chinese/Latin wrapping and measured layout at 200% scale; generated sample text-pair contrast; fresh versioned package compilation and scenario execution. Platform dynamic data is a deterministic host-adapter example, not OS wallpaper acquisition.

Not claimed: formal conformance to every upstream MCU revision/variant/contrast level; pixel-identical native shadows; spring playback by all later components; every platform's Chinese font fallback; manual screen-reader behavior; Android or real-desktop scenario verification; AOT/trimming. Those are either explicitly outside this theme-input contract or assigned to component/#20 acceptance. There is no silent omission of a promised token family.
