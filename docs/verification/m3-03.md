# M3-03 / issue #4 — Verification evidence

## Scope and boundaries

The [component contract](../components/m3-03.md) delivers action/icon variants, XS/S/M/L/XL sizes, shapes, width modes, two-state toggle, slots, commands, input, automation, theme consumption and the compiled package gallery. Tests use the preconfirmed public theme/control + equivalent host seams from SPEC/testing.md: real Avalonia headless input, Skia-rendered pixels/frames, public properties, command/result text and automation providers. No private template-part assertions or mocked internal collaborators are used.

Windows native evidence is a **real desktop application**, OS UI Automation, native mouse injection and SendKeys keyboard input. It is not a human screen-reader test or physical touch-device test. Headless touch contacts exercise Avalonia's touch pipeline, not Android hardware.

## Final commands and evidence

The delivered verifier runs **the complete merged suite**, including preserved #2, full #3 and #8 scenarios. The final documented configuration contains **124 source tests** and **132 isolated package tests**, all executed, zero failures/skips. The issue-specific source class contributes 72 cases; the actual compiled Gallery page adds four cases (including both 320/1100-DIP 200% layouts).

```powershell
dotnet test tests/Avalonia.Material3.Tests -c Release --disable-build-servers
pwsh -NoProfile -File scripts/verify-issue4.ps1 -DesktopSmoke
pwsh -NoProfile -File scripts/verify.ps1 -DesktopSmoke
```

The issue verifier packs to a unique feed, copies consumers/scenario C# files/fixtures **without the library project**, restores in a unique cache, runs PackageConsumption.Tests through actual package/library/Gallery assemblies and builds ButtonsHost with warnings-as-errors. Native smoke then checks:

1. named Favorite has Button role and initial Toggle Off;
2. Invoke executes CommandParameter and updates the visible result;
3. native mouse click executes the same command/result;
4. Toggle selects; Tab focuses the icon; Space deselects; Enter selects;
5. disabling exposes IsEnabled=false without losing selection; a cached Invoke is rejected and result stays unchanged;
6. mode and 200% font controls execute, with native screenshots;
7. the owned process is closed in finally.

Observed native disabled rejection is `System.Exception`, HRESULT **-2146233088**, from Avalonia's COM projection. Public peer tests assert ElementNotEnabledException. The smoke checks rejected operation/no mutation; it does **not** claim native HRESULT conformance.

Final successful full runs (both exit 0):

- `pwsh -NoProfile -File scripts/verify-issue4.ps1 -DesktopSmoke`: 124 source + 132 package cases; ButtonsHost build 0 warnings/errors; native smoke passed; fresh sandbox `m3-issue4-02b888d87fb944b18b6eb12ff00278a6` was removed normally.
- `pwsh -NoProfile -File scripts/verify.ps1 -DesktopSmoke`: 124 source + 132 package cases; original Gallery and StandaloneHost both passed their native automation/Tab/Space/mode smoke; fresh sandbox `m3-consumer-049ed8a2d09b49888f25aec8ac6189bd` was removed normally.

TRX output: `artifacts/TestResults/issue4/source.trx`, `package.trx`; normal verifier writes `artifacts/TestResults/source.trx`, `package-consumption.trx`. Images are regenerated under `artifacts/screenshots/issue4` and selected copies are committed here. One restore attempt timed out after a SkiaSharp native-asset EOF; it was not counted as passed. Earlier test/native runs returned nonzero during cleanup because the shared compiler retained an Avalonia BuildServices collector DLL. Retry alone was insufficient: the issue verifier now disables node reuse and shared compilation for its own invocations, restores the caller's environment, and retries sandbox cleanup without shutting down unrelated agents' build processes. Those incomplete commands are not called full successful verification runs.
