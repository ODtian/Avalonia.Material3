## Limits and remaining manual/platform acceptance

- Automatic scroll is an **offset-driven Avalonia projection**, not a Compose NestedScrollConnection/fling engine. ApplyScrollDelta is the optional host pre-consumption seam. Host owns page offset/history restoration.
- One semantic/visual title changes role at collapse threshold, rather than duplicate crossfading titles. Scroll layout/presentation commits are immediate; no claim of travelling/crossfade/spring/predictive-back/frame/pixel/native-shadow equality. Shared button state layers consume live reduced-motion resources.
- Solid background blending uses documented RGBA interpolation, not an assertion of Compose color-space engine equality. Semantic endpoints/defaults are independently checked.
- 720 DIP is the **example-host** breakpoint, not a normative token. Tiny windows below required touch/bar minima cannot guarantee page space; host owns localization/assets/fonts/platform back and input adapters.
- Source/framed headless touch and RTL geometry are real evidence but **not physical touch hardware**. Native desktop evidence is Windows LTR with the listed keys/UIA/mouse/wheel/resizes, not every platform/input combination.
- Borrowed aggregate-root gating is source/fresh-package tested; final aggregate/native published host remains #20 work. Use the optional window-root host rather than leaving aggregate navigation outside modality.
- No human NVDA/Narrator session, Android software keyboard/insets/predictive back, macOS/Linux, NativeAOT/trimming, stable release/API baseline or literal product App upgrade was performed by this ticket.

Manual screen-reader recipe (unexecuted): launch the package AppChromeHost; use Tab/Up/Down/Space to enter Library, verify spoken destination name/selected state; open Details and return; narrow window, open Navigation menu, verify outer controls are unavailable and only one title/subtitle instance is announced; open confirmation, Back closes dialog then Escape closes drawer and returns focus; at200% read/scroll full long titles and destination labels. Record actual spoken order/announcements with the chosen reader before claiming that human acceptance.
