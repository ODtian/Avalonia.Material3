本票据沿用 `docs/SPEC.md` 中用户已确认的组件展厅／等价通用宿主入口，以及 Issue #2 的 M04、M07、M09 验收。测试只穿过公开消费契约，不测试内部协作者、私有方法或模板子元素名称。

每个行为采用单独的 red → green 周期；规范默认值来自锁定的 AndroidX 参考令牌，而不是被测代码的计算结果。
