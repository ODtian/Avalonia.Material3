## Delivered forms

These are real templated/drawn feedback controls, not aliases for unstyled Avalonia controls.

| Control | Forms | Pinned default visual geometry |
|---|---|---|
| `MaterialLinearProgressIndicator` | Determinate/indeterminate, standard/Expressive wave | Width240; stroke4; round caps; gap4; determinate stop4. Standard height4; wave height10, amplitude3, wavelength40 determinate /20 indeterminate |
| `MaterialCircularProgressIndicator` | Determinate/indeterminate, standard/Expressive wave | Standard40; wave48; stroke4; gap4; radial wave amplitude1.6, preferred wavelength15 rounded to an integral wave count |
| `MaterialLoadingIndicator` | Indeterminate seven-shape cycle; determinate circle→soft-burst morph; either contained or uncontained | Container48; active silhouette bounded within38; contained full-round shape |

The loading cycle is **SoftBurst → Cookie9Sided → Pentagon → Pill → Sunny → Cookie4Sided → Oval → repeat**. Pinned rounded vertices/radii, a continuous angular-sampled silhouette morph, quarter-turn morph rotation and 4666ms global rotation are implemented. Cycle interval is650ms. Determinate loading morphs and rotates counter-clockwise according to the reported value. Containment uses PrimaryContainer/OnPrimaryContainer; uncontained loading and progress use Primary, tracks use SecondaryContainer. A standard indeterminate circular indicator has no track; its wave form does.

Standard determinate values are immediate, matching the reference's default: the library does not invent animated task progress. Waves travel one wavelength per second; determinate amplitude is zero at≤10% and≥95%, and changes use the effective Long2 duration and increasing/decreasing M3 easings. Standard/Expressive indeterminate linear motion uses the1750ms two-segment cadence (head/tail delays0/250/650/900ms and durations1000/1000/850/850ms). Circular activity uses the6000ms sweep/global rotation and300ms additional quarter turns within1500ms intervals.

### Normative pin and Avalonia projection boundary

The pin is AndroidX **`11ece46a49d485c7644e53cb0684a611d7a0ec10`**, `LinearProgressIndicatorTokens`, `CircularProgressIndicatorTokens`, `LoadingIndicatorTokens` **v0_7_0**, `ProgressIndicator.kt`, `WavyProgressIndicator.kt`, its internal drawing modifiers, `LoadingIndicator.kt` and `MaterialShapes.kt`. [Verification and direct links](../verification/m3-11.md) distinguish numeric defaults from platform projections.

Avalonia wave rendering uses sampled sinusoidal paths, not Compose's cubic/rounded-star `PathMeasure` engine. Loading rounds the pinned polygon vertices, samples240 angular rays and interpolates corresponding silhouettes, rather than claiming to port AndroidX's feature-matching `Morph` algorithm. The loading spring consumes the **live M3 SlowSpatial token** (Expressive default0.8/200), not the upstream component-local0.6/200 pair. This is an explicit theme-driven Avalonia playback projection. Shape families, order, dimensions, cadence and actual visible morphing are delivered; formal frame/pixel/velocity identity to Compose is **not** claimed.

## Public host inputs

All writable inputs are Avalonia StyledProperties and support bindings. The library never starts, awaits, cancels, pauses, retries or schedules an application task.

```xml
<m3:MaterialLinearProgressIndicator
    xmlns:m3="using:Avalonia.Material3.Controls"
    Value="{Binding ImportFraction}"
    Status="{Binding ImportStatus}"
    ResultMessage="{Binding ImportResult}" IsExpressive="True"
    AutomationProperties.Name="Import documents" />

<m3:MaterialLoadingIndicator xmlns:m3="using:Avalonia.Material3.Controls"
    IsContained="True" Status="{Binding ImportStatus}"
    ResultMessage="{Binding ImportResult}"
    AutomationProperties.Name="Import documents" />
```

| Input | Contract |
|---|---|
| `Value` | Normalized0..1; out-of-range/infinite values clamp; NaN becomes0. Host-owned and not changed by completion. Effective rendered/accessible completion value is1; idle is0. Value1 alone does **not** complete an operation |
| `Status` | `MaterialProgressStatus`: Idle, Running, Paused, Completed, Failed. Default Running. Arbitrary enum values rejected. Host explicitly chooses every transition |
| `IsIndeterminate` | Default false for linear/circular, true for loading. Numeric progress is unavailable to automation while activity is indeterminate; terminal/idle feedback is no longer indeterminate |
| `IsExpressive` | Selects visible wave geometry for linear/circular; not a loading variant selector |
| `ResultMessage` | Optional host text on Completed/Failed. Results replace ongoing animation with a check/cross, and display wrapped status text. Failed glyph consumes Error; success glyph consumes Primary. This terminal result presentation is a library feedback adaptation, not an upstream progress-indicator variant |
| `AnimationTime` | Nullable nonnegative TimeSpan. Null: attached UI frame clock. Non-null: host-controlled absolute time with no frame timer. The first value establishes a baseline; subsequent deltas advance active animation. Rewinding resets the cycle. Changing clock domains establishes a baseline without a time jump |
| `TrackBrush`, `ErrorBrush`, inherited `Foreground` | Local values override live semantic role defaults, according to normal Avalonia precedence |
| `MotionSpring`, `MotionDuration`, `AccelerateEasing`, `DecelerateEasing`, `ProgressEasing` | Component playback overrides using #3's existing MaterialSpring, TimeSpan and Avalonia IEasing types; normally supplied by DynamicResource, not another theme API |

Loading adds `IsContained`, `ContainerBrush`, `ContainedForeground`, `ContainerCornerRadius`. The radius must have finite, nonnegative corners. The contained radius follows `M3.Shape.CornerFull`; brushes follow the active semantic scheme. Base state inputs and `Template`/`Theme` remain usable.

Read-only observable `StatusDescription` describes the effective state (e.g. `Running, 40%`, `Paused, indeterminate`, `Completed: 12 documents imported`). English state labels are defaults; percentage formatting uses the current culture. Hosts requiring localized semantics should supply `AutomationProperties.ItemStatus` and their own localized status content/template. `GraphicWidth`/`GraphicHeight` are read-only template metrics; the linear width is NaN (available width). Private presenters, child names and the sampled path implementation are **not** extension API.

## Activity, pause, terminal and reduced motion

```csharp
// UI thread; application owns this task and its IProgress adapter.
indicator.Status = MaterialProgressStatus.Running;
indicator.Value = 0;
try
{
    await ImportAsync(progress); // host reports Value on the UI thread
    indicator.ResultMessage = "12 documents imported";
    indicator.Status = MaterialProgressStatus.Completed;
}
catch (Exception error)
{
    indicator.ResultMessage = error.Message;
    indicator.Status = MaterialProgressStatus.Failed;
}
```

- Paused freezes rendered animation and exposes a visible/accessible paused description. It does **not** freeze a Value binding or pause application work. The host must implement its desired work-pause policy. Resume excludes paused time and continues the retained phase.
- Completing/failing stops animation immediately and retains the result until the host changes Status. Late Value/time reports cannot revive activity. Running after Idle/Completed/Failed starts a new cycle; Running after Paused resumes it.
- Runtime `theme.Motion = theme.Motion with { ReduceMotion = true }` zeroes effective durations/marks springs instant via #3. Existing controls immediately snap: linear unknown progress has a fixed visible segment, circular unknown feedback has a static partial arc, loading has the first pinned shape. Determinate values and outcome text stay meaningful. Re-enabling motion starts from this canonical phase without accumulating reduced-motion wall time.
- Own visibility/disabled state and detachment stop the frame timer; detached or disabled time is excluded. Ancestor-hidden feedback does not advance, but may retain its bounded frame-observation timer so that ancestor visibility can resume without losing the clock baseline. Hosts can explicitly pause or detach hidden pages to eliminate those observations. Reattachment establishes a new clock baseline. The only library timer is a16ms UI render-frame timer, not a task scheduler.
- Disabled feedback uses #3's disabled surface/foreground tokens and keeps host values/results. Local brush overrides have normal Avalonia priority.

## Layout, input and automation

Active circular/loading graphics retain their compact40/48-DIP dimensions. Idle/paused/result status containers use240-DIP default text width while their graphics stay compact at the leading edge, preventing short status words from breaking into individual letters. Text wraps and grows with the BodyMedium role. Hosts can override Width/MaxWidth or replace the template; deliberately constrained local widths also constrain descriptions. Linear RTL mirrors its active segment, gap, track and stop. Circular progression is clockwise from twelve o'clock for determinate values.

Feedback is noninteractive and nonfocusable by default: it must not steal Tab focus from start/pause/retry actions. Give it `AutomationProperties.Name` describing the operation, not an animation frame. Automation exposes **ProgressBar**, live **ItemStatus**, and read-only **RangeValue**0..1 only for determinate/terminal/idle feedback. Range mutation throws; no Invoke/Toggle action is invented. Numeric/status change notifications are raised; native provider availability is cached safely for off-UI-thread pattern queries. Template children are not duplicate accessible controls. Hosts own localized/live announcements; the sample's result TextBlock is a polite live region. Human screen-reader reading is not asserted by API/UIA checks.

A replacement `Template` keeps host state and automation but must provide its own shape, status, contrast and motion presentation. No private template part is an external contract.
