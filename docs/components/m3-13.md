# M3-13 — Menus, Tooltip and Snackbar

Namespace: `Avalonia.Material3.Controls`. Avalonia 12.1.3 / net10.0; install `MaterialTheme` and use a bounded **MaterialOverlayHost** as the window/root content. All mutation and commands run on the UI thread. These are actual Material ControlThemes, not unstyled standard MenuItems or native popups renamed as Material controls.

## Menu consumption

```csharp
var export = new MaterialMenuItem
{
    Content = "Export", Submenu = new MaterialMenu
    {
        Items = { new MaterialMenuItem { Content = "PDF", Value = "pdf" } }
    }
};
var menu = new MaterialMenu
{
    Variant = MaterialMenuVariant.Standard,
    Items = { new MaterialMenuItem { Content = "Copy", Value = "copy" }, export }
};
var session = menu.Show(overlayHost, opener);
session.Closed += (_, result) =>
{
    if (result.Reason == MaterialOverlayCloseReason.Confirmed)
        hostSelectedOperation = result.Value; // Application result; no implicit navigation.
};
```

- `MaterialMenu : ItemsControl`: `Variant` **Standard / Vibrant / LegacyDropdown**, `IsSegmented`, inherited Items / ItemsSource, `IsOpen`, `Session`, `Show(host, anchor, options?)`, `ShowContext(host, target, localPoint)`, `AttachContext(host,target)` → disposable, `Dismiss()`.
- Items are **MaterialMenuItem controls**, **MaterialMenuGroup controls**, or decorative controls such as `MaterialDivider`. ItemsSource may supply these controls. Arbitrary data models must be mapped to the public item controls by the host; this version does not advertise generated-data-container selection/navigation.
- `MaterialMenuGroup : ItemsControl`: `Orientation` Vertical/Horizontal, host-driven `IsActive` (default true); groups inherit the menu variant. Horizontal groups distribute available width and wrap into additional rows when a 48-DIP target would otherwise be clipped.
- `MaterialMenuItem : Button`: native `Content/ContentTemplate`, `Command/CommandParameter/Click`, `IsEnabled`, and Template/Theme seams; `Value`, `LeadingIcon`, `TrailingIcon`, `SupportingText`, `TrailingText`, `IsIconOnly`, `Submenu`, `ToggleMode` None/Check/Radio, `IsChecked` (TwoWay), `GroupName`, `StaysOpenOnClick`. Icon-only content requires a meaningful `AutomationProperties.Name`.
- Arrow-key highlight/focus is **not** checked/selected state. Check toggles; radio chooses one member of the same GroupName in the same menu. SetCurrentValue preserves TwoWay bindings. `StaysOpenOnClick=false` (default) confirms a host Value and closes the chain; true executes/toggles without completing the presentation.
- Commands run **only** after top-session and cancelable Closing approval. CanExecute=false cannot activate. A synchronous command or Click exception leaves the presentation open and does not publish a confirmed result. A command must not mutate the overlay stack; perform follow-up presentation after completion instead. Host side effects before an exception cannot be rolled back by the library.
- One root menu per host, one child submenu per parent. Opening a new root/sibling closes the previous chain; covered/vetoed replacement is rejected rather than creating a second stale actionable menu. Submenus consume the same overlay stack and are modeless above the modal root; no second native Popup focus trap exists.
- Initial focus selects the first enabled visible row. Up/Down wrap and skip decorative/disabled rows; Home/End choose endpoints. Logical forward opens a submenu and backward returns to the parent (reversed in RTL). Horizontal groups use logical Left/Right. Enter/Space retain Button activation. Escape dismisses the deepest submenu first. **Tab dismisses the chain and returns to the opener** (it does not implicitly activate an item or advance to an arbitrary background tab stop).
- Type-ahead uses public TextInput and current-culture prefix matching with a one-second reset. Empty/all-disabled menus are focusable safe scopes, closable by Escape/Tab/host back.
- `AttachContext` installs actual ContextRequested (right-click/holding) plus Menu key/Shift+F10 paths. Pointer coordinates are target-local DIP, not screen pixels. The binding is removed on dispose/detach. Manual `ShowContext` needs no fake input.
- Root options are modal with **no visible scrim**, focus take/return, light-dismiss, Anchor, 8 horizontal / 48 vertical window margins. Outside click dismisses, not a background action/click-through. Explicit options may replace this policy. Anchor resize/scroll/RTL follows live transforms and clamps; root/anchor detachment completes the dependent chain; hide/disable and window deactivation request cancellation (veto/covered requests remain pending). Removing/disabling rows reconciles focus.
- Automation exposes Menu/MenuItem, names, disabled state, Invoke, toggle state/notifications, supporting HelpText, and submenu ExpandCollapse. This is an **in-window menu tree**, not an OS menu bar or an out-of-window Popup.

## Menu token recipes and explicit projections

The pinned sources are [MenuTokens], [StandardMenuTokens], [VibrantMenuTokens], [SegmentedMenuTokens] and [MenuDefaults].

| Recipe | Container / selected content |
| --- | --- |
| LegacyDropdown | SurfaceContainer, radius4, elevation3 DIP; selected SecondaryContainer / OnSecondaryContainer, LabelLarge |
| Standard expressive | SurfaceContainerLow; label OnSurface, support/icons OnSurfaceVariant; selected TertiaryContainer / OnTertiaryContainer |
| Vibrant expressive | TertiaryContainer / OnTertiaryContainer; unselected interactive icons Tertiary; selected Tertiary / OnTertiary |
| Segmented | Either expressive color recipe; outer16, group padding4/gap2, active first/middle/last directional16/8 corners, inactive8; item4, selected12, first/last12 outer corners |

Item label/support/trailing support are BodyLarge / BodyMedium / LabelSmall with **all five live typography metrics**. Icons20 DIP; item content gap12; segmented padding16×8; horizontal padding12×6; icon-only padding16; minimum **48-DIP target** around the smaller visual recipe. Horizontal hover/focus/press radius12; selected horizontal shape is Full (clamped capsule). Menu width112..280, outer vertical padding8; content scrolls instead of reserving normal layout space. Live hover/focus/press state layers and reduced-motion-aware state duration are consumed.

The library deliberately names legacy versus expressive selection roles; it does not silently combine SecondaryContainer legacy selection with expressive Tertiary selection. Segmented + LegacyDropdown is rejected. Standard disabled content uses OnSurface ×.38; selected/vibrant content/container use the appropriate roles with a **single** .38 attenuation. The missing generated selected-disabled trailing-support opacity is projected as .38 consistently, not claimed as an upstream constant. Desktop precision padding16/12/10/12 combined with the token20-DIP icons is an explicit Avalonia recipe, not a claim to reproduce every Compose density overload. Standard components animate state layers; opening/closing the in-window presentation is instantaneous, not a reproduction of Compose scale.8→1/origin/spring frames. Shadows are #3 Avalonia projections.

## Tooltip consumption

```csharp
var tip = new MaterialTooltip
{
    Variant = MaterialTooltipVariant.Rich,
    Title = "Backups", Content = "Keep a safe copy.",
    ActionContent = "Learn more", ActionResult = "learn"
};
using var attachment = tip.Attach(overlayHost, anchor); // Optional user-input binding.
// Manual invocation remains independent of EnableUserInput:
var session = tip.Show(overlayHost, anchor);
```

- `MaterialTooltip : ContentControl`: `Variant` Plain/Rich, `Title`, Content/ContentTemplate, `ActionContent/ActionTemplate/ActionCommand/ActionParameter/ActionResult`, `IsActionEnabled`, readonly `CanInvokeAction`, `IsPersistent`, `EnableUserInput` (true), `ShowOnDisabled` (false), `ShowCaret` (false), `Placement` Above(default)/Below/Start/End/Left/Right, `ShowDelay`400ms, `LongPressDelay`500ms, `Duration`1500ms, `IsOpen/Session`, `Attach`, `Show`, `InvokeAction`, `Dismiss`.
- One tooltip per host, not an unbounded global strong-reference service. Supersession closes the prior tooltip; covered/vetoed replacement is rejected, not queued.
- Manual/default and long-press nonpersistent shows expire at1500ms. **Hover persists while hovered** after400ms; pointer exit dismisses a nonpersistent plain tooltip. **Keyboard focus persists until focus loss/Escape**, not1500ms. Pointer-driven focus is not treated as keyboard focus. Rich actionable tooltips are effectively persistent while the user reaches/uses the action; Tab from the anchor enters it. Tab/Enter, disabled action, Escape and conditional focus return use the same action/session path.
- Plain tips and ordinary timed feedback never take or restore focus. Rich focus is returned to an attached usable anchor **only if it was in the rich tip when closing**, and the return does not immediately reopen the tip. Pointer exit across anchor→rich content does not destroy the action path.
- Attach provides a live anchor HelpText relation for initial string content **only if the host has not supplied HelpText**. Dispose removes its binding, timers and input/root handlers; explicit host descriptions are preserved.
- Long press is a configurable Avalonia 500ms / 8-DIP slop projection, not a TooltipTokens value. The same public TimeProvider drives it. The accepted touch/stylus path releases anchor capture, handles release and suppresses the anchor's ordinary click. Capture cancellation, movement and detach cancel the pending trigger; Avalonia Holding is also recognized. Physical platform gesture arbitration still requires real-device verification.
- Default options: modeless/no scrim/no focus take or unconditional restore; anchor4-DIP spacing, flip/clamp and window margin8. Optional caret adds an8-DIP triangular template projection plus4-DIP free gap and points toward the actual flipped side; exact caret shape/size is not a generated token claim.
- Plain: InverseSurface/InverseOnSurface, radius4, BodySmall, padding8×4, min40×24, max width200, no elevation. Rich: SurfaceContainer/OnSurfaceVariant, radius12/elevation3, TitleSmall/BodyMedium, Primary/LabelLarge action, max width320/horizontal16; real baseline layout gives first title baseline28 and title→body baseline24 at scale1. Larger fonts/content grow spacing rather than overlap; custom nontext content uses a safe leading-edge projection. Action target≥48 (reference visual min36); body-bottom16/action-bottom8.
- Tooltip role/name and polite live metadata are exposed; anchor HelpText and native rich action peers are accessible. **These metadata are not a claim that NVDA/Narrator speaks the message.**

## Snackbar consumption / lifecycle

```csharp
var snackbar = new MaterialSnackbar
{
    Content = "Saved", ActionContent = "Undo", ActionResult = "undo",
    ActionCommand = hostUndoCommand, ActionParameter = hostUndoContext
};
var result = await snackbar.Show(overlayHost).Completion;
// Confirmed → accepted action; cancellation/timeout never runs an implicit application undo.
```

- `MaterialSnackbar : ContentControl`: message Content/ContentTemplate; ActionContent/ActionTemplate/ActionCommand/ActionParameter/ActionResult; `IsActionEnabled`, readonly `CanInvokeAction`; `ActionOnNewLine`; localizable `DismissText` ("Dismiss"); `Duration` nullable TimeSpan; `IsOpen/Session`, `Show(host, timeProvider?, cancellationToken?, options?)`, `InvokeAction`, `Dismiss`, accepted `ActionInvoked`.
- Duration null: **4000ms without action, indefinite with action**. Explicit10000ms gives reference Long; `Timeout.InfiniteTimeSpan` is indefinite. Host may extend reading duration for accessibility. Reduced motion never shortens a reading timeout. Finite durations are0..49 days (valid System timer range).
- **No hidden queue/service**: a host-driven visible surface and lifetime are the delivered contract. Only one Snackbar per host; replacement dismisses the current item or throws if covered/vetoed. Hosts that want a queue sequence their own requests by Completion. This is not advertised as Compose's fair-mutex SnackbarHost service.
- A cancellation already requested throws before creating a visual or taking focus. Shown cancellation/timeout sets a pending ending state and disables action; if covered it waits for top ownership. Closing veto leaves the actual session open. Detach forcibly completes through the overlay host. Disposed timers/registrations are generation-local; old callbacks cannot complete a new presentation.
- Action-versus-timeout/close races have one accepted outcome. No action executes behind a covered presentation, after timeout is pending, when disabled or CanExecute=false. Closing veto and synchronous command exceptions do not publish successful results. A command must not change the overlay stack during commit. `ActionInvoked` is after accepted closure; asynchronous application work belongs to the host.
- Default presentation: Bottom, margin12, modeless/no scrim/no focus take/restore, Escape/back through the generic host. Dismiss button is always reachable, including indefinite feedback. Message/action/dismiss grow and scroll at narrow/short/large-font sizes; ActionOnNewLine is host-controlled and layout also stacks when necessary.
- Tokens: InverseSurface / InverseOnSurface / InversePrimary action, radius4, elevation6, message BodyMedium, action LabelLarge, dismiss glyph24. Minimum48, two-line content naturally grows to≥68; max width600, message horizontal16 / vertical14, action-side8. Adaptive line flow is intentional, not fixed68-height clipping.
- Named Pane/message, polite LiveSetting, name-change notifications and real named Button/Invoke actions; no focus stealing or implicit undo service.

## Template and reusable overlay extensions

Ordinary Content/ContentTemplate/Theme/Template and font/brush/shape properties remain public. Surface action templates must retain `Button` parts **PART_ActionButton**, and Snackbar **PART_DismissButton**, or explicitly call the public InvokeAction/Dismiss methods from their own controls. Menu item replacement templates keep Button input; custom visuals own state/focus/touch rendering. Layout helpers `MaterialFeedbackPanel` and `MaterialTooltipPanel` document the message/action/dismiss and title/body/action three-child ordering.

This ticket extends the shared session without copying the overlay shell:

- `MaterialOverlaySession.IsTop`: public top ownership query.
- `Close(value, Action)`: top-session/Closing approval precedes the synchronous action; a throwing action leaves the session open. Normal reentrant closes return false; Show during commit throws; forced host/anchor teardown still completes and cannot deadlock.
- `MaterialOverlayOptions.AnchorPosition`: Below/Above/Start/End/Left/Right; `AnchorPoint`: optional anchor-local context DIP point. Side preferences flip and clamp; offset gap changes sign after the corresponding flip. Existing default Below placement remains compatible.

The host retains modality, LIFO completion, forced cancellation, focus and congruent automation scope. See [M3-12](m3-12.md).
