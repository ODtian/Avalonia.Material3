# M3-05 — Button groups, segmented options and split actions

Namespace: `Avalonia.Material3.Controls`. Install the independent `MaterialTheme` before content. This uses the complete [M3-02 resources](m3-02.md) and [M3-03 button contracts](m3-03.md), not FluentTheme, a fallback palette, a separate font scale or product-specific icons. Development package remains `0.1.0-preview.1`; #20 owns release/API versioning.

## Groups and selection

`MaterialButtonGroup : Panel` lays out `MaterialGroupButton : MaterialButton` children. Add/remove/reorder `Children` on the UI thread; assign strings, controls or ContentTemplates to the normal button content/leading/trailing slots. Commands, parameters, handled Click, access keys, enabled/CanExecute, pointer capture/cancel, Space/Enter and template replacement retain the #4 foundations.

| Public input/result | Default | Contract |
| --- | --- | --- |
| `Variant` | `Unconnected` | Unconnected (12 DIP visual spacing) or Connected (2 DIP) |
| `SelectionMode` | `None` | None = actions; Single = one choice; Multiple = independent options |
| `AllowEmptySelection` | false | In Single mode retain a required selection; true permits deselecting it. Multiple always permits empty selection |
| `SelectedItem` | null / TwoWay | First selected child; assigning a current child selects it, replacing the choice in Single mode and adding it in Multiple. Assign null with AllowEmptySelection to clear |
| `SelectedItems` | read-only snapshot | Selected children in collection order; empty in action mode |
| `SelectionChanged` | event | Committed result changed, before activating Click/Command; a handler may redirect the choice |
| `Orientation` | Horizontal | Horizontal, or vertical connected/action grouping with logical top/bottom shapes |
| `ExpandedRatio` | .15 | Unconnected press expands up to 15%, sharing compression between adjacent children; finite 0..1 override |
| `Spacing` | read-only double | Actual recipe spacing (segmented = -1 border overlap) |

Undefined enum values and invalid ratios are rejected. Host selection does not click/run a command. User updates use SetCurrentValue, preserving TwoWay selection bindings. Disabling does not clear a choice. A required Single group chooses its first enabled child when necessary; an empty/all-disabled group cannot invent an enabled selection. Removing a selected item reconciles the result. Action mode hides, but does not erase, stored child IsChecked values. Returning to selection mode reconciles them.

The group owns child `IsToggle` according to SelectionMode. Do not independently bind it to a contradictory mode. In Multiple mode use each child's TwoWay `IsChecked` to bind individual options; `SelectedItems` is a result, not a mutable collection. A SelectedItem must belong to the current Children collection. `Children` supports ordinary layout controls, but only MaterialGroupButton children participate in the selection contract.

```xml
<m3:MaterialButtonGroup xmlns:m3="using:Avalonia.Material3.Controls"
                       Variant="Connected" SelectionMode="Multiple">
  <m3:MaterialGroupButton Content="Photos" IsChecked="{Binding Photos}" />
  <m3:MaterialGroupButton Content="Videos" IsChecked="{Binding Videos}" />
</m3:MaterialButtonGroup>
```

Connected normal leading/trailing ends consume full outer corners and Small (8) inner corners; middle children use Small. Press consumes ExtraSmall (4) inner corners; selection changes the connected shape to full round. Press takes priority over selected shape. RTL swaps start/end; vertical grouping uses top/bottom ends. Each reflowed horizontal row gets its own end shapes. Colors/size/type/slots still come from the #4 button recipe; connected is not a new palette.

## Segmented options

`MaterialSegmentedButtonGroup : MaterialButtonGroup` defaults to required Single selection. Set `SelectionMode=Multiple` for multiselect. Both are genuine outlined segmented templates, not ordinary buttons with a renamed class.

- Pinned Small visual minimum 40 DIP, LabelLarge, 18 DIP indicator/icon, 8 DIP icon gap, 1 DIP Outline stroke.
- Equal-width cells and one-DIP shared-border overlap; selection does not change row widths.
- Selected: SecondaryContainer / OnSecondaryContainer. Unselected: transparent / OnSurface.
- Disabled selection stays selected with SecondaryContainer, content OnSurface × live DisabledForegroundOpacity (.38); disabled outline uses the generated token's OnSurface × DisabledContainerOpacity (.12). The pinned Compose implementation instead uses Outline × .12 for its disabled border; this projection explicitly chooses the generated OutlinedSegmentedButtonTokens recipe.
- `MaterialGroupButton.SelectionIcon` defaults to a check glyph. Selected segments replace LeadingIcon with this indicator; Content/ContentTemplate and trailing slots remain host-owned. Supply licensed icon assets if desired; no icon font is bundled.
- Local size/appearance/template overrides retain input/semantics, but the documented pinned segmented recipe is Small. None mode is inherited for host extensions, not advertised as an upstream segmented variant.

```xml
<m3:MaterialSegmentedButtonGroup xmlns:m3="using:Avalonia.Material3.Controls" SelectionMode="Single">
  <m3:MaterialGroupButton Content="Day" />
  <m3:MaterialGroupButton Content="Week" />
  <m3:MaterialGroupButton Content="Month" />
</m3:MaterialSegmentedButtonGroup>
```

## Overflow and narrow layouts

Unconnected horizontal groups keep a fitting prefix and expose the remainder through a filled icon **More options** entry. Public `OverflowButton`, `OverflowItems`, `OverflowEntries`, `IsOverflowOpen`, `OpenOverflow()` and `CloseOverflow()` support host customization/testing. OverflowItems identifies original actions; entries are temporary MaterialButton surfaces in a scrollable, light-dismiss Popup. Enter/Space/Invoke/Toggle execute the original action/selection/Command exactly once, then close and return focus. Up/Down/Home/End navigate the enabled menu entries; Escape closes. IsEnabled, string content and selection are live bindings to the originals. The original visibility binding is not overwritten: overflow temporarily removes its visual from the row, retaining its logical item and public state.

Complex Control content cannot have two parents. Overflow displays its explicit AutomationProperties.Name (or a textual fallback) rather than duplicating that control. **Give complex items a meaningful automation name.** The popup is a compact action/option projection, not the entire menu API assigned to #15. Full rich menu/submenu variants are not claimed here.

Connected groups reflow into readable rows rather than hiding choices. Segmented cells divide available width equally, wrap labels and start another row if keeping 48-DIP targets requires it. Vertical groups remain stacked. The parent reserves 5 DIP at each horizontal edge for the focus ring; small controls reserve vertical focus space. Horizontal visual gaps are pinned 12/2/-1; vertical envelopes additionally reserve focus-ring space, so vertical visual gaps are not claimed pixel-identical to Compose.

Text wraps under finite width, height grows, and split sides share a common visual height. **Adaptive long-content policy:** after content grows beyond nominal height, full outer/selected corners are capped at half the nominal container height. This prevents a tall vertical capsule curving underneath multiline labels. At nominal height all pinned full/inner/selected shapes remain unchanged. This is an explicit readable-content adaptation, not upstream multiline pixel parity. Arbitrary huge interactive content, host clipping, explicit sub-minimum dimensions and custom templates remain host responsibilities. Put long galleries/forms in a ScrollViewer. Below the minimum width for two separate split targets (plus gap/focus reservation), use a wider container or host layout alternative rather than claiming impossible targets fit.

## Split actions

`MaterialSplitButton : Panel` exposes stable `MainButton` and `SecondaryButton` (`MaterialSplitButtonPart : MaterialButton`). They are distinct focus/input/automation surfaces; never one hit target with coordinate-based synthetic clicks.

| Public input | Default | Meaning |
| --- | --- | --- |
| `Size` | Small | XS, S, M, L, XL from the #4 enum |
| `Variant` | Filled | Filled / Tonal / Elevated / Outlined; Text recipe rejected |
| `SecondaryIsToggle` | true | Secondary activation toggles IsExpanded; false is a plain independent action |
| `IsExpanded` | false / TwoWay | Host-owned option/content expanded state, committed before secondary Click/Command; programmatic changes do not invoke actions |

Set each part's Content, ContentTemplate, icon slots, Command/Parameter, Click and IsEnabled independently. Parent IsEnabled disables both. Main activation neither toggles expansion nor runs the secondary command. Secondary activation never runs main. Host supplies the actual contextual content/menu (the gallery demonstrates destination options changing the main action label). A `Button.Flyout` remains Avalonia's host extension; the host must synchronize its Opened/Closed state with IsExpanded if using it. The group is not a hidden automatic menu service.

Secondary defaults to a chevron content slot. `UseIconContent=true` scales Content/ContentTemplate to the pinned secondary icon size; false renders a normal text/data-template action slot. `RotateSecondaryContent=true` rotates the icon 180 degrees while selected using the effective state-layer transition; disable for host-controlled/icon animation or text. It does not rotate a text-secondary slot.

```csharp
var split = new MaterialSplitButton { Size = MaterialButtonSize.Medium, Variant = MaterialButtonVariant.Tonal };
split.MainButton.Content = "Save";
split.MainButton.Command = saveCommand;
split.SecondaryButton.Content = "⌄"; // or host icon/template
AutomationProperties.SetName(split.SecondaryButton, "Save options");
split.SecondaryButton.Click += (_, _) => options.IsVisible = split.IsExpanded;
```

Pinned SplitButton*Tokens `18_0_18` dimensions (DIP):

| Size | Visual min height | Main start/end padding | Secondary padding each side | Secondary icon | Normal inner / pressed inner |
| --- | ---: | --- | ---: | ---: | --- |
| XS | 32 | 12 / 10 | 13 | 22 | ExtraSmall 4 / Small 8 |
| S | 40 | 16 / 12 | 13 | 22 | ExtraSmall 4 / Medium 12 |
| M | 56 | 24 / 24 | 15 | 26 | ExtraSmall 4 / Medium 12 |
| L | 96 | 48 / 48 | 29 | 38 | Small 8 / LargeIncreased 20 |
| XL | 136 | 64 / 64 | 43 | 50 | Medium 12 / LargeIncreased 20 |

Spacing is 2 DIP at all sizes; outer normal corners are Full; selected secondary becomes Full, pressed inner wins. Main vertical padding, leading icon, typography and recipe elevation/states consume #4's size roles. Selection retains the action's normal recipe and adds a pressed-alpha state layer, not the generic toggle palette. The pinned source applies pressed/selected shape changes, not the unused generated hovered-inner token; hover retains normal shape with the standard state/elevation feedback.

Read-only observable `GroupCornerRadius`, `SplitCornerRadius`, `SecondaryContentSize`, `SecondaryRotation`, and `SharedContainerHeight` expose target geometry for templates/host observation, **not rendered spring-frame measurements**. Full target radii are normalized by the internal #4 shape driver. Internal child names are not public API. The minimal protected `MaterialButton.CommitToggleSelection()` hook permits required selection to stay selected without publishing transient Off/On states; ordinary #4 button behavior and direct Button inheritance remain unchanged.

## Input, accessibility and motion

- Pointer/touch in-bounds release activates once; release outside cancels. Disabled/CanExecute-false surfaces reject activation without selection/action mutation.
- Tab/Shift+Tab use Avalonia navigation. Arrows/Home/End navigate enabled visible group choices without selecting; Enter/Space commit selection. RTL and vertical logical edges are preserved. Multiple can independently toggle every option.
- Split main and secondary have separate Tab stops; F4 / Alt+Down activate the secondary entry; Escape collapses host options and restores secondary focus. Sibling contextual content should implement the same Escape return (as the gallery does).
- Group role Group, Selection provider with live required/multiple/selected list. Single choices expose RadioButton + SelectionItem; Multiple expose CheckBox + SelectionItem/Toggle; action mode exposes Button/Invoke without selection. SelectionContainer points to the owning group. Select changes choice without invoking an action; invalid Add/Remove on a required single group throws. State changes raise automation property notifications.
- Split container role Group, main Button/Invoke, secondary Button/Invoke and conditional ExpandCollapse. It reports whether a host Flyout exists via ShowsMenu; expansion itself can be non-menu content. Give icon-only/complex content explicit names. Cached provider/mode availability avoids off-UI-thread StyledProperty reads during native UIA queries.
- All targets are at least 48×48 DIP under the delivered templates. Focus rings, state layers and disabled states are visible separately rather than fading whole controls.
- Connected/split morphs use #4's effective DefaultEffects spring; unconnected width uses effective FastSpatial (15% target, neighbor compression bounded to 16 DIP each and minimum target width). State alpha and chevron use effective StateLayerDuration. Runtime ReduceMotion snaps playback; detach stops timers/subscriptions. The bounded analytic projection retargets from current position and does not claim Compose velocity/frame/pixel identity, including segmented indicator movement.
