# M3-06 — Checkbox、Radio 与 Switch 消费契约

归属：[#5](https://github.com/ODtian/Avalonia.Material3/issues/5)。规范基线为覆盖矩阵锁定的 **2026-10-04** / AndroidX **11ece46a49d485c7644e53cb0684a611d7a0ec10**。这是标准选择控件的实现契约，不是上游全平台像素一致性或人工读屏认证。

## 安装与类型

沿用 [公开包初始化](../public-contract.md)和 [M3-02 完整主题输入](m3-02.md)。net10.0 / Avalonia 12.1.3，当前预览包版本不在本票单独提升。

```xml
<PackageReference Include="Avalonia.Material3" Version="0.1.0-preview.2" />
```

在 App.Initialize 中、创建内容之前安装 `Avalonia.Material3.Themes.MaterialTheme`。选择控件使用独立 `SelectionControls.axaml` 的 ControlTheme/ControlTemplate；**并非给未设置样式的原生控件改名**。不需要 FluentTheme 或 SimpleTheme 才能显示这些 Material 控件。

命名空间 `Avalonia.Material3.Controls`：

| 类型 | Avalonia 基础 | 标准值/语义 |
| --- | --- | --- |
| `MaterialCheckBox` | `CheckBox` | `IsChecked=false/true/null`；null 是 mixed/indeterminate |
| `MaterialRadioButton` | `RadioButton` | 两态，GroupName 单选互斥；null 归一为 false，IsThreeState 始终 false |
| `MaterialSwitch` | `ToggleSwitch` | 两态开关，null 归一为 false，IsThreeState 始终 false；保留拖动基础 |

没有另造与 Avalonia 冲突的 Selected/Value 状态。`IsChecked` 是继承的、默认 TwoWay 的 StyledProperty；`IsCheckedChanged` 是继承的路由事件。表单的业务值由宿主模型持有：单选值通过 GroupName 内各项的 IsChecked 与宿主值映射贯通。

## 标准尺寸与状态

尺寸单位是 DIP；标准控件不是按钮的 XS/S/M/L/XL 变体。

| 组件 | 默认视觉尺寸 | 输入区域 |
| --- | --- | --- |
| Checkbox | 18×18、2 圆角、未选中 2 描边；check 或 mixed 横线 | 至少 48×48 |
| Radio | 20×20、2 描边、选中 10×10 中心点 | 至少 48×48 |
| Switch | 52×32、16 圆角、未选中 2 描边；off handle 16、on handle 24、pressed handle 28 | 默认 64×48，包含状态层/焦点环空间 |
| Switch thumb icon | 可选 16×16 内容；off 有图标时 handle 为 24 | 同一开关输入区域，不是独立按钮 |

Checkbox/Radio 的状态层是 40×40；Switch 的 40×40 状态层随 handle 移动。默认 hover/focus/pressed/dragged alpha 为 .08/.10/.10/.16，来自 MaterialTheme.States。键盘有可见焦点环；disabled 不显示活动状态层/焦点环。

- 未选中轮廓、选中填充/中心点、mixed mark 都有实际模板视觉。
- Checkbox disabled indicator 使用 OnSurface × DisabledForegroundOpacity（默认 .38），check/mixed 使用 Surface。
- Radio disabled indicator 同样使用 OnSurface × .38。
- Switch disabled selected track 使用 OnSurface × DisabledContainerOpacity（默认 .12）、Surface handle；disabled off **保留 SurfaceContainerHighest 填充**，仅 OnSurface outline 使用 .12、handle 使用 OnSurface × .38。不能把整个 off track 淡化到 .12。
- 字体放大/长标签会增长控件高度，不按 48 截断文本。标准 indicator/track 尺寸不随字体放大；触达区域不会缩小。

宿主可以使用 Width/MinHeight/Padding 等 Avalonia 布局属性增加尺寸，但不应把触达区域减到标准最小值以下。

## 值与表单绑定

```xml
<StackPanel xmlns="https://github.com/avaloniaui"
            xmlns:m3="using:Avalonia.Material3.Controls">
  <m3:MaterialCheckBox Content="Notifications / 通知"
                      IsThreeState="True" IsChecked="{Binding Notifications}" />
  <m3:MaterialRadioButton Content="Email" GroupName="delivery"
                         IsChecked="{Binding EmailSelected}" />
  <m3:MaterialRadioButton Content="Post" GroupName="delivery"
                         IsChecked="{Binding PostSelected}" />
  <m3:MaterialSwitch Content="Auto save" IsChecked="{Binding AutoSave}" />
</StackPanel>
```

- Checkbox 默认为二态，false → true → false；启用 IsThreeState 后为 false → true → null → false。宿主也可直接赋 null 表达 mixed。
- Radio 点击已选项不会取消选择。非空 GroupName 使用 Avalonia 的根级分组；无名组按共同父节点。不同表单应使用不同的显式 GroupName。
- Switch 只有 off/on；不要用它表示 mixed。
- 指针、键盘与 automation 操作产生的值变化贯通宿主绑定；随后恢复模型值仍能更新原控件，不需要重建控件。
- 持久化、业务枚举、验证规则、文件/数据库 I/O 属于宿主，不由控件库管理。

## 错误与禁用公开契约

三个类型各自公开 `IsError` (`bool`, 默认 false) 与 `ErrorText` (`string?`, 默认 null)，以及相应 StyledProperty 字段。

```xml
<m3:MaterialCheckBox Content="Accept terms" IsError="True"
                    ErrorText="Review this preference / 请检查" />
```

IsError 只表达宿主校验反馈，**不修改值、不自动禁用、不决定业务合法性**。默认模板显示 ErrorText，并通过 Error/OnError 角色表达状态；有 disabled 时禁用视觉优先。复杂表单自行把 DataValidationErrors 或自己的验证结果映射到这两个属性。

CheckboxTokens 明确有 error variant。RadioButtonTokens 和 SwitchTokens 没有独立的 normative error variant；这两者的 Error 描边/选中 track 与错误说明是公开的**宿主验证扩展**，不能宣传为上游新增标准变体。

ErrorText 在 IsError=true 时作为 automation HelpText 的 fallback；显式 AutomationProperties.HelpText 优先。请提供非空错误说明，不只依靠颜色。这里不承诺自动 live-region 播报；人工读屏检查仍属于平台验收。

## 输入、焦点与 automation

- 指针点击/触摸释放激活；从普通点击区域移出后释放取消。
- Switch handle 支持 Avalonia ToggleSwitch 的拖动，释放按 endpoint 选择值；拖动不是“移出即取消”的普通点击。
- Tab/Shift+Tab 沿用 Avalonia 焦点导航，Space 按下有 pressed、释放改变值；Enter 沿用 Button 基础。
- MaterialRadioButton 增加方向键：Right/Down 选下一项，Left/Up 选前一项，循环、跳过 disabled/不可见/不可聚焦项、不跨 GroupName 或窗口。方向键操作保持 TwoWay 绑定。这里不另造 roving-tab 容器；每个可聚焦 radio 仍可通过 Tab 访问。
- `IsEnabled=false` 不接受指针/触摸/键盘/automation 操作，不参加正常 Tab 导航。
- 标准内容沿用 Avalonia 内容名称；复杂内容使用 AutomationProperties.Name。
- Checkbox 与 Switch 暴露 CheckBox UIA role + TogglePattern（Windows UIA 没有 Switch role）；checkbox 的 null 暴露 Indeterminate。
- Radio 暴露 RadioButton role + SelectionItemPattern；保留 Avalonia 的 selection/toggle 通知与禁用保护。GroupName 的互斥由原生 RadioButton 基础负责。

真实 Windows UIA 与原生 Space/方向键证据见 [M3-06 验证](../verification/m3-06.md)。这不是 Narrator/NVDA 人工读屏或物理触摸设备认证。

## 主题与扩展插槽

所有颜色来自 M3-02 完整角色资源，没有本票私有调色板或另一套主题 API：Primary/OnPrimary、Secondary、OnSurface/OnSurfaceVariant、Outline、Surface、SurfaceContainerHighest、PrimaryContainer/OnPrimaryContainer、Error/OnError。

标签使用 BodyLarge 字体/字号/字重/行高/字距资源；Typography 的 per-role 字体、Scale 与普通字体回退在已显示控件上更新。State layer/disabled alpha 使用 MaterialTheme.States；Opacity transitions 使用 `M3.StateLayerDuration`，ReduceMotion 归零。Handle 位移使用原生 ToggleSwitch 的 `KnobTransitions`（Canvas.Left），尺寸和填充使用同步的框架过渡，内部32 DIP固定框保持图标/handle同心；外部52×32 track与64×48输入区域不参与过渡。持续拖动/pressed按原生契约即时跟随，释放恢复过渡。DurationShort4/EasingStandard资源在已显示实例上实时更新；减少动效会取消当前过渡并归位。这是基于标准缓动的Avalonia投影，仍不冒称AndroidX Expressive spring/ripple像素一致性。

- `Content` / `ContentTemplate`：标签和宿主内容；默认字符串换行。
- Checkbox / Radio / Switch 保留继承的 Command/CommandParameter/Click 与 IsCheckedChanged；保存数据应观察值变化，而不依赖每次选择都产生 Click（方向键、handle drag 是选择变化）。
- Switch 保留 `OnContent`/`OffContent` 与对应模板，默认 null；可展示状态说明。
- Switch 新增 `OnIcon`/`OffIcon` (`object?`) StyledProperty 内容槽。保持 16 DIP 范围，图标是装饰，默认不命中测试/不作为独立 automation 控件。
- `Theme` / `Template` 可替换。Checkbox/Radio 的基本输入与 automation 不依赖模板子元素；自定义模板须自行保留触达、内容、焦点、selected/mixed/error/disabled 视觉。
- Switch 替换模板时须保留 Avalonia ToggleSwitch 的 `PART_MovingKnobs`（Panel，必需）、`PART_SwitchKnob`（Panel，保留拖动）、`PART_ContentPresenter` 与可选 `PART_OnContentPresenter`/`PART_OffContentPresenter`。这些是继承基础的公开 template-part 契约，不是建议依赖默认模板的私有子元素名。
- 局部 Background/BorderBrush/Foreground、FontFamily/FontSize/FontWeight 等值按 Avalonia 优先级覆盖主题。自行覆盖 indicator/track 颜色或替换模板时，宿主也负责相应错误/禁用/对比度处理。

## 展厅、保存/恢复与独立桌面示例

`Gallery.Pages.SelectionFormPage` 是独立公开 StackPanel，可用无参构造或传入当前 MaterialTheme。它通过包 API 展示：

- 业务数据示例 `SelectionFormData(bool? Notifications, string Delivery, bool AutoSave)`，Delivery 为 Email/Post。
- mixed 初值、radio value 映射与 switch TwoWay 绑定；Save/Reset/Restore 可重复运行。
- Save 把输入保存为 JSON；Reset 保留已保存 JSON；Restore 完整校验 delivery 后恢复原控件。
- **23** 个标准值/disabled/error/icon 状态比较与三种控件的中英长标签。
- light/dark、100/200% 字体按钮；可改变窗口宽度检查换行。

例子：`{"Notifications":null,"Delivery":"Post","AutoSave":true}`。JSON 使用 source-generated context；示例存储只是宿主内存字符串，不冒充磁盘持久化。

最终聚合 gallery 导航接入由 #20 完成；本页已通过等价宿主与真正编译 Gallery assembly 的隔离包测试。`samples/SelectionDemo` 是直接运行同一页的 PackageReference 桌面消费者，使用 Avalonia.Themes.Simple **只提供滚动条/ScrollViewer scaffold**，库本身不依赖它，也不以 Simple 模板替代 Material 控件。
