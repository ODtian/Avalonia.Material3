# M3-10 · Sliders / 滑块公开消费契约

归属：[Issue #8](https://github.com/ODtian/Avalonia.Material3/issues/8)。场景证据：[M3-10 verification](../verification/m3-10.md)。安装主题及版本化包的基础步骤见[公开消费契约](../public-contract.md)。本票不改变 `Material3Version`，最终发布版本由 M3-19 / #20 管理。

## 范围与锁定参考

- `MaterialSlider`：连续、离散、带标记、中心起点轨道、水平/垂直、反向和 RTL。
- `MaterialRangeSlider`：连续或离散的有序双端点范围；两个独立键盘焦点及自动化值提供器。
- 模板不是重命名的普通 Avalonia Slider：16 DIP 活动/非活动轨道、把手侧 2 DIP 内圆角与外端圆头、4 × 44 DIP 圆头把手、按下/聚焦 2 DIP 把手、把手两侧 6 DIP 间隙、4 DIP 标记及停止点、值指示器、禁用状态和可见焦点。
- 依据覆盖矩阵锁定的 AndroidX 提交 `11ece46a49d485c7644e53cb0684a611d7a0ec10`：[`SliderTokens.kt` v2_3_5](https://github.com/androidx/androidx/blob/11ece46a49d485c7644e53cb0684a611d7a0ec10/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/tokens/SliderTokens.kt)、[`Slider.kt`](https://github.com/androidx/androidx/blob/11ece46a49d485c7644e53cb0684a611d7a0ec10/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/Slider.kt) 及 [Material sliders](https://m3.material.io/components/sliders/overview)。
- preview.3 几何修复：绘制、两个48-DIP端点目标及 pointer inverse 共用一个轴模型。保留24-DIP触达边距；轨道外边与内缩8-DIP圆头中心不是同一个位置。离散内部值与标记在圆头中心域内插值，精确 min/max 把手仍到外边；连续值仍使用完整值域。停止点只在确实存在的非活动端轨道上绘制，range/centered 两侧一致；活动标记为 SecondaryContainer，而非值指示器字体画刷。范围标签只在实际相交时分离，不无条件移往相反半窗。鼠标/焦点窄把手的可见间隙仍为6 DIP，不改设置/自动化值。
- 显式 `Marks` 是不改变可选值的装饰性扩展；其视觉位置采用圆头中心域，`Step=0` 连续值映射仍使用外边域。要让停止值和标记严格共位，使用离散 `Step`。这些选择与字体/设备尺度各自独立；物理证据边界见 [manual-quality-geometry](../verification/manual-quality-geometry.md)。
- 控件使用 **数值间隔 `Step`**，不是 Compose 的“内部停止点数量 `steps`”。等距范围 0..10、Step=2 的可选值是 0、2、4、6、8、10。

命名空间：`Avalonia.Material3.Controls`。框架仍是 Avalonia 12.1.3 / net10.0；Slider 本身没有新增运行时包或产品业务依赖。完整主题使用 #3 的 MaterialColorUtilities 0.3.0 依赖，见 [M3-02 契约](m3-02.md)。

## 使用

```xml
<StackPanel xmlns="https://github.com/avaloniaui"
            xmlns:m3="using:Avalonia.Material3.Controls">
  <m3:MaterialSlider Minimum="0" Maximum="100" Value="{Binding Brightness}"
                     LabelFormat="0'%'" AutomationProperties.Name="Brightness" />
  <m3:MaterialSlider Minimum="0" Maximum="100" Step="10" ShowMarks="True"
                     Value="{Binding Volume}" AutomationProperties.Name="Volume" />
  <m3:MaterialRangeSlider Minimum="0" Maximum="24" Step="1" ShowMarks="True"
                          LowerValue="{Binding StartHour}" UpperValue="{Binding EndHour}"
                          LowerLabel="Start hour" UpperLabel="End hour"
                          ValueLabelVisibility="Always"
                          AutomationProperties.Name="Active hours" />
  <m3:MaterialSlider Minimum="-100" Maximum="100" CenteredTrack="True" />
  <m3:MaterialSlider Orientation="Vertical" Height="180" Value="50" />
</StackPanel>
```

为绑定示例提供相应 DataContext / `x:DataType`。初始化时，先设置适当的 bounds，再设置所需值。绑定范围使用 `LowerValue` / `UpperValue`；不要同时给继承的 `Value` 和 `LowerValue` 绑定不同源。

## 属性与值语义

除 `ValueText` 外，下表均为 StyledProperty，支持样式、局部值和绑定。

| 属性 | 默认 / 契约 |
| --- | --- |
| `Minimum`, `Maximum` | 0、100；只接受有限 double。设 Minimum 高于 Maximum 会同步提高 Maximum；反向设 Maximum 会同步降低 Minimum。相等 bounds 是合法的单点范围 |
| `Value` | 0；有限值、默认 TwoWay。范围控件上与 LowerValue 同步；输入通过 SetCurrentValue 保留消费者绑定 |
| `Step` | 0；有限、非负。0 为连续；正值为从 Minimum 起的间隔 |
| `LowerValue`, `UpperValue` | 范围默认 0、100；真实 TwoWay StyledProperty；始终 `Minimum <= LowerValue <= UpperValue <= Maximum`；允许两端点相等 |
| `ShowMarks` | false；只影响外观，不改变可选值 |
| `Marks` | 空只读列表；元素必须有限。替换列表才能通知控件，不原地修改共享列表。空列表配合正 Step 自动生成标记；非空列表仅绘制 bounds 内标记，不把这些位置变成离散停止点 |
| `LabelFormat` | `0.##`；有效 .NET double 数字格式，使用当前文化；例如 `0'%'`。非法标准格式在赋值时拒绝 |
| `ValueLabelVisibility` | `OnInteraction`；枚举 `Never` / `OnInteraction` / `Always`。交互状态为拖动或控件内键盘焦点 |
| `ValueText` | 当前下端/单值的格式化 CLR 读取属性；不是绑定通知源。实时预览绑定 Value/LowerValue/UpperValue，或订阅公开 PropertyChanged |
| `LowerLabel`, `UpperLabel` | `Lower value`、`Upper value`；范围端点的可本地化读屏名称后缀 |
| `Orientation` | Horizontal；Vertical 默认从下向上增长 |
| `ReverseDirection` | false；反转轨道和方向键对应方向。水平 FlowDirection=RightToLeft 自动反向；与显式 ReverseDirection 异或组合 |
| `CenteredTrack` | false；单值活动轨道从 bounds 中点开始；范围控件始终以两个端点间为活动轨道 |
| `Foreground`, `Background` | 继承的画刷分别表示活动/把手和非活动轨道；局部覆盖沿用 Avalonia 优先级 |
| `ValueIndicatorBrush`, `ValueIndicatorForeground` | 值指示器容器和文字画刷；可公开覆盖 |
| `DisabledActiveOpacity`, `DisabledInactiveOpacity` | 有限 [0,1] double；默认 0.38、0.12，分别从 `M3.DisabledForegroundOpacity` / `M3.DisabledContainerOpacity` 动态获取；分别作用于活动/把手及非活动轨道，不是整控件透明度 |

**归一化**：先夹入 bounds，再选择最近的 `Minimum + n * Step` 或 Maximum；等距时取较大的值。两端点一直可到达，即使最后一个区间短于 Step。例如 10..95、Step=20 的值为 10、30、50、70、90、95；40 归一为 50，94 为 95，Left 从 95 到 90。

范围值不能互相跨越：尝试将下端拖到上端之后时停在上端，不交换端点身份；上端反之。批量恢复时可先把下端降到 Minimum，再恢复上端和下端，展厅示例采用此顺序。NaN/Infinity、负 Step 等拒绝且不替换现有有效状态。极端 finite bounds 使用防溢出的插值；小于 double 可表示精度的步长无法创造不可表示的新值。密集自动标记按可见间距抽稀，单帧最多绘制 4096 个标记，不减少可选值。

## 实际输入契约

- 左键/触摸按下定位当前值并捕获该 pointer；拖动和释放连续更新公开值。拖到轨道外夹到端点。
- 范围按离点击最近的端点调整；距离相同取上端，重合时向较低值点击可分开下端、向较高值点击可分开上端。整个手势保持同一端点。
- 仅首个捕获 pointer 控制当前手势；丢失捕获、移除控件或禁用会终止拖动，保留最后的有效值；不会像取消按钮点击那样回滚设置。
- 单值一个 Tab 焦点；范围按下端、上端两个 Tab 焦点。禁用不参与导航、不响应 pointer/keyboard/automation 调值。
- Left/Down 减少，Right/Up 增加；反向轨道反转方向键。离散为前一个/后一个停止点；连续为全范围的 1%。PageDown/PageUp 减少/增加 10 个停止点或 10%；Home/End 到最小/最大有效值。范围移动仍受另一端点约束。
- 指针悬停反馈、按下窄把手、可见焦点环；目标至少 48 DIP。默认无动效，无需用 ReduceMotion 隐藏或延迟值变化。

## 自动化与主题

单值 peer 是 Slider，支持 RangeValue：名称来自 AutomationProperties.Name / LabeledBy，暴露 Value、bounds、SmallChange、LargeChange、可用状态与 IsReadOnly。ItemStatus 默认返回带单位的格式化值；宿主可覆盖 ItemStatus。调值使用与 pointer / keyboard 相同的归一化；禁用 SetValue 抛 InvalidOperationException。值、bounds 和只读变化发送公开自动化属性通知。

范围父 peer 是 Group；下端、上端各自是可聚焦的 Slider / RangeValue provider。名称是“父名称 + 可本地化端点标签”，各端点的自动化 bounds 受另一端点约束。默认 presenter 在重设模板后复用端点及 peer 身份。**这些是自动化接口证据，不是人工读屏或原生平台桥验收。**

语义角色：Primary、SecondaryContainer、InverseSurface、InverseOnSurface，全部直接来自完整 M3-02 MaterialTheme 的 DynamicResource；`Sliders.axaml` 已删除起始阶段的三个本地颜色 fallback，不定义平行的颜色角色或主题输入 API。SeedColor、平台 DynamicColors、RequestedThemeVariant 的实时切换及清除覆盖后的恢复均更新已显示的 slider。

禁用活动/把手使用 OnSurface × DisabledForegroundOpacity（默认 0.38），非活动轨道使用 OnSurface × DisabledContainerOpacity（默认 0.12）；跟随 `MaterialTheme.States` 更新，任一 opacity 为零也不影响另一轨道。字体使用 M3.LabelLargeFontFamily / FontSize / FontWeight，包含 per-role 字体与字重覆盖、全局字体回退和尺度；值指示器按控件实际字体及字重绘制。

默认横向尺寸至少 48 × 64 DIP，值指示器预留区域随字体尺度增长；垂直交换主轴。过长数字/格式文本在有限的值指示器区域内裁剪；应为极端数值使用紧凑格式（例如 G3），在旁边放置可换行的完整设置标签/预览。无障碍仍可读取完整格式值及数值。默认模板的固定几何来自锁定令牌；通过 Template 更改几何属于宿主责任。

## 模板扩展

`Template` / `Theme` 可覆盖。默认公共模板部件是 `MaterialSliderPresenter`，命名为 **PART_Surface**；它承载 M3 轨道、端点命中区域和端点 automation。包装该 presenter 可增加应用内容而保留交互；让 presenter 占用与控件一致的轨道几何。示例：

```xml
<ControlTemplate xmlns="https://github.com/avaloniaui"
                 xmlns:m3="using:Avalonia.Material3.Controls">
  <Border>
    <m3:MaterialSliderPresenter x:Name="PART_Surface" />
  </Border>
</ControlTemplate>
```

替换而不保留此部件的自定义模板须自行承担范围端点导航/automation 和视觉契约；不是默认模板已覆盖的情况。不依赖私有绘制元素名称。

## 展厅与包消费

独立公共页面：`samples/Gallery/Pages/SliderSettingsPage.cs`，类 `Gallery.Pages.SliderSettingsPage`。仅用发布库 API；Gallery 项目保持 PackageReference，不引用库源码。M3-19 / #20 负责将各独立页面加入 aggregate gallery。

页面含连续亮度、离散音量、范围时段、中心平衡、垂直水平与禁用状态；公开 Preview 随值变化更新。Save settings 保存到本地 JSON，Reopen saved settings 重新读取；重新创建页面也恢复。默认路径为 LocalApplicationData/Material3Gallery/slider-settings.json，也可传入宿主指定路径。存储及业务文案留在宿主，控件库不依赖文件系统。保存使用 source-generated JSON 元数据，但本票未作 AOT 验收。

窄窗口动作行可换行；长标签/预览使用 TextWrapping。页面是 StackPanel，短窗口的滚动容器及通用滚动样式由 gallery shell / 宿主提供；测试明确使用足够高的等价窗口，不冒充短窗口完整滚动验收。

```powershell
pwsh -NoProfile -File scripts/verify-sliders.ps1
```

此脚本先跑源码场景，再 pack 到新目录，以全新 NuGet cache 构建并运行 package consumers、同一 slider 场景和真实页面保存/恢复场景。源码项目不复制进消费 sandbox。可加 `-KeepSandbox` 调试；默认清理。构建禁用复用 build servers，避免临时包缓存被 build-service DLL 锁住。测试入口、红绿证据及真实平台缺口见验证记录。
