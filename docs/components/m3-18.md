# M3-18 — Carousel & pull-to-refresh

The four image collection forms and both refresh feedback forms are implemented as actual M3 templates and interactive layouts. The host owns image acquisition, collection changes, application work and its outcomes. No network, image decoder, repository, task scheduler or business requests are added to the library.

## Locked references and projection policy

The existing coverage baseline is unchanged: **2026-10-04**, AndroidX commit [`11ece46a49d485c7644e53cb0684a611d7a0ec10`](https://github.com/androidx/androidx/tree/11ece46a49d485c7644e53cb0684a611d7a0ec10). Component references:

- [Carousel guidelines](https://m3.material.io/components/carousel/overview), pinned [`Carousel.kt`](https://github.com/androidx/androidx/blob/11ece46a49d485c7644e53cb0684a611d7a0ec10/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/carousel/Carousel.kt).
- Pinned [`PullToRefresh.kt`](https://github.com/androidx/androidx/blob/11ece46a49d485c7644e53cb0684a611d7a0ec10/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/pulltorefresh/PullToRefresh.kt), including its standard and Expressive indicator alternatives.

| Form | Implemented behavior | Avalonia projection / limitation |
| --- | --- | --- |
| Multi-browse | Complete pinned Arrangement cost search, small40–56/anchor10 keylines, continuously interpolated adjusted/unadjusted coordinates, Strategy start/end shifts and snap offsets | Content remains measured at its full focal width. Short collections retain already focal start items when the entire scroll range is an end shift. |
| Uncontained | Pinned cut-off medium-size calculation and Strategy; stable large content, free fractional pointer release; nearest current index and keyboard/programmatic navigation | Host position is mapped through the same continuous keyline presentation. |
| Hero | Pinned start-aligned Hero arrangement and the shared boundary Strategy; viewport target with a trailing small mask | All focal content stays at the complete stable width while its mask changes. |
| Full-screen | One edge-to-edge viewport image; **vertical** tracking/paging, Up/Down, zero item corner radius | “Full-screen” fills the control's viewport; does not change OS window state, safe areas or host navigation. |
| Standard refresh |40 DIP SurfaceContainerHigh/full-shape/Level2 container; reference pull arrow progress and tension; busy circular feedback | Busy16 DIP spinner is a scaled #12 circular indicator, including its stroke/animation projection, not a copy of Compose's spinner engine. |
| Expressive refresh | Contained #12 loading, pull-driven determinate circle→shape, busy seven-shape loading, primary-container/on-primary-container roles | Inherits #12's explicit Morph/PathMeasure/spring projection boundaries. The48×48 #12 container is retained; no separate loading engine is invented here. |

The committed `carousel-keylines.json` contains216 vectors from independent execution of the original pinned Kotlin algorithms. Public host scenarios compare real caller measurement, painted position and hit ownership across three strategies, four viewport sizes, three item counts and six fractional/boundary positions. Full-screen keeps its vertical viewport-sized layout. Native frame and visual acceptance use the final package producer.

## `MaterialCarousel`

Namespace `Avalonia.Material3.Controls`; `TemplatedControl`, focusable. Install `MaterialTheme` before constructing a host.

```csharp
var images = new ObservableCollection<MaterialCarouselItem>
{
    new() { Title = "Forest / 林", Image = decodedImage },
    new() { Title = "Ocean / 海", State = MaterialCarouselItemState.Loading }
};
var carousel = new MaterialCarousel
{
    ItemsSource = images,
    Layout = MaterialCarouselLayout.MultiBrowse,
    Height = 220,
    PreferredItemWidth = 186,
    ItemSpacing = 8 // pinned default is0; sample explicitly adds spacing
};
carousel.CurrentItemChanged += (_, _) => hostStatus.Text = carousel.PositionDescription;
carousel.ItemRetryRequested += (_, e) => host.RetryImage(e.Item);
```

`MaterialCarouselItem : AvaloniaObject`: bindable `Title`, `IImage? Image`, `State` (`Ready`, `Loading`, `Failed`), `ErrorMessage`, and optional `Content`. A supplied image remains visible behind loading/error feedback; the library neither owns nor disposes its image. The host must marshal state changes to the UI thread and dispose decoders/images when it knows consumers no longer use them.

The default error message uses at most two visual lines with ellipsis so a long mixed-language error at200% typography cannot displace the Retry action outside the image. Its full `Text`/accessible name remains available. Failed tiles omit the separate footer so it cannot intercept Retry. Replacement templates own their equivalent overflow/accessibility policy.

| API | Contract |
| --- | --- |
| `ItemsSource` | Ordered `IEnumerable<MaterialCarouselItem>`; `INotifyCollectionChanged` automatically reconciles changes. For a plain enumerable, assign a new sequence to notify changes. Items are non-null. |
| `CurrentIndex` | Default0, default TwoWay, clamps to available bounds. Empty collections use0 with `CurrentItem=null`. User input uses `SetCurrentValue`, retaining bindings. |
| `CurrentItem`, `PositionDescription`, `CanMoveNext/Previous` | Read-only observable position/boundary feedback; description includes1-based position, title and image state. |
| Collection updates | Retain **object identity** where it remains in the new collection, including insertion/move; otherwise clamp the old index. Removing the final item shows `EmptyText` (default “No items”). Hosts can explicitly restore/reselect their domain IDs after replacing models. |
| `Layout` | MultiBrowse / Uncontained / Hero / FullScreen. Horizontal forms honor RTL; full-screen remains vertical. |
| `PreferredItemWidth` | Default186, finite and at least48. Multi-browse target; uncontained uses the pinned item-plus-spacing recipe bounded to viewport. Hero uses its viewport target around the required small mask. |
| `ItemSpacing` | Default0, nonnegative finite DIP. |
| `ItemTemplate` | `IDataTemplate` receives the **item**, not its image or index. Owns replacement image/state/content rendering. Content is measured at a stable large width and masked by the item container; no private part names are an extension contract. |
| `MotionDuration`, `MotionEasing` | Default pager settlement uses the reference unit-mass spring (damping1, stiffness200). Default recipe reconfiguration is immediate. Explicitly setting `MotionDuration` opts into the authored duration/easing path, including optional recipe interpolation; zero ends settlement immediately. |
| `AnimationTime` | Nullable absolute nonnegative time. Null uses an attached UI rendering clock. Useful for deterministic hosts/capture; a rewind finishes a pending settle. |
| `PresentationPosition` | Read-only fractional visual position. During a drag it can differ from current index; uncontained retains the free release fraction. |
| `MoveNext/Previous()` | Bound-aware enabled navigation; returns whether the current index changed. |
| `ItemRetryRequested` | Named Retry action reports the original item; host decides how to retry and reports loading/result. No implicit loader is started. |

### Input and access

- Primary mouse/touch/stylus contact only. Axis-dominant movement (>12 DIP,1.5× cross-axis dominance) tracks visible masks. Snapping forms commit one neighboring item at25% of the preferred width bounded by the viewport (full-screen: viewport height); uncontained preserves continuous distance. These input-policy values are declared Avalonia policy, not component token values.
- Tap a visible image peek to select it. Nested buttons/editors/sliders retain their own input/commands; the carousel does not turn an item action into selection.
- Horizontal arrows (RTL aware), vertical Up/Down for FullScreen, PageUp/Down, Home/End. Tab reaches the collection; keyboard focus is visible. Escape, capture loss, disable, detach or collection changes cancel an in-flight gesture.
- A named **List** peer exposes Scroll, logical position percent and ItemStatus; full-screen advertises vertical scrolling. Disabled native provider actions reject mutation. ViewSize describes a logical current-item page, not physical masked-pixel visibility. Images have their full titles and Retry buttons have item-specific names. There is no misleading toggle/SelectionItem contract.
- Generated images/captions consume one live `M3.DisabledForegroundOpacity` each when disabled; no parent opacity doubles that fade. Supplied template/content controls retain their own disabled styling obligation.
- Resizing recalculates masks but preserves the current item/index and normalized visual position. Detach stops the clock and unsubscribes from collection/model notifications.

## `MaterialPullToRefresh`

`ContentControl` with arbitrary `Content` / `ContentTemplate`, bindable standard or Expressive feedback, reusable gesture and F5/Invoke entry. Minimum48 DIP; visible keyboard focus.

```csharp
var refresh = new MaterialPullToRefresh { Content = carousel, IsExpressive = true };
refresh.RefreshRequested += async (_, _) =>
{
    try
    {
        // Application code. Apply the returned content on the UI thread.
        await host.UpdateImagesAsync();
        refresh.ResultMessage = "6 photographs updated";
        refresh.Status = MaterialProgressStatus.Completed;
    }
    catch (Exception e)
    {
        refresh.ResultMessage = e.Message + "; retry available";
        refresh.Status = MaterialProgressStatus.Failed;
    }
};
```

- `Status` reuses #12 `MaterialProgressStatus`, default **Idle**, default TwoWay. Completing a valid request sets **Running feedback** before raising `RefreshRequested`; it does **not** perform work. `RefreshCommand` / `CommandParameter` are an optional command equivalent; CanExecute is respected. Event precedes command when both are supplied.
- Running/Paused suppress duplicate requests. The host owns pause policy and terminal outcome; `Completed` / `Failed` hide pull feedback and show wrapped `ResultMessage`/accessible result. No timeout or automatic success is invented. Failed/Completed can request again.
- `Threshold` defaults **80 DIP**, positive finite; physical pull uses the pinned **0.5 resistance multiplier**. Refresh requires adjusted distance **strictly greater** than threshold and **release**, not just reaching it. Raw160 DIP does not trigger with defaults.
- `DistanceFraction`, `IsArmed`, `IsPulling` and `StatusDescription` are read-only observable feedback. Overshoot follows pinned `t - t²/4`, with tension clamped0..2; position max2× threshold.
- `IsAtStart` is the host boundary for arbitrary content. A nested `ScrollViewer.Offset.Y>0` is also rejected at gesture start. This is an Avalonia pointer adapter, **not Compose nested-scroll consumption**: if a drag begins away from the top and reaches the top, release and start a fresh pull. There is no retroactive takeover of that drag.
- Horizontal gestures remain available to nested carousels. Once a vertical pull is claimed, the wrapper captures/focuses and cancels child capture. Escape/capture loss/disable/detach/IsAtStart=false/content replacement cancel before requesting. Cancellation does not cancel an already-started host task.
- F5, `RequestRefresh()` and the Group peer's Invoke action are accessible alternatives, not fabricated touch input; they work independently of the current scroll boundary.
- Standard feedback consumes full #3 surface/foreground/elevation roles. Expressive feedback consumes #12's contained loading and reduced-motion behavior. Content stays stationary; the indicator overlays the top of the viewport.
- In a short viewport the visual indicator displacement is capped at the viewport height so busy feedback remains visible even at48 DIP. The80 DIP gesture threshold/resistance contract does **not** change with that visual adaptation.

## Gallery, package and scope

`Gallery.Pages.CarouselRefreshPage` is an actual PackageReference consumer with all four forms, standard/Expressive refresh switch, image failure/retry, add/remove, controllable async refresh, failure/recovery and real generic `DrawingImage` landscapes. Injectable host operation is a system-boundary seam, not a mock of library internals. It replaces all form collections and explicitly restores position. It owns a ScrollViewer so every form remains reachable at320 DIP/200% fonts. Dispose the page when the host closes to cancel its demo tasks.

`samples/BrowseHost` consumes the same compiled gallery and the versioned package, with runtime light/dark,320/900 width and100/200% font controls. `scripts/verify-issue19.ps1` packs into a new feed/cache/no-library-src sandbox before testing; source-linked equivalent scenarios are not mislabeled as the actual compiled-gallery package checks.
